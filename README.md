# Real-Time Group Chat

A client-server chat application built to practise real-time communication with Socket.IO.

## Features

- Shared group room
- Join notifications
- Real-time messages
- Typing indicators

## Tech stack

React, Vite, Tailwind CSS, Node.js, Express, Socket.IO

## Run locally

```bash
cd server && npm install && npm start
cd client && npm install && npm run dev
```

Run the server and client in separate terminals.
